# 🔗 URL Shortener

## 📖 Description

This project is a simple and responsive URL Shortener developed using HTML5, CSS3, and JavaScript.

It allows users to enter a long URL and generate a shortened link using the is.gd public API. Users can copy the shortened URL and view their recent shortened links through the history section.

## ✨ Features

- 🔗 Shorten long URLs
- ✅ URL validation
- 🌐 Public API integration
- 📋 Copy shortened URL to clipboard
- 🕘 History of shortened URLs
- 💾 History stored using localStorage
- ⚠️ API error handling
- 📱 Responsive design
- 🔄 Dynamic DOM updates

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- DOM Manipulation
- Local Storage
- Clipboard API
- is.gd URL Shortening API
